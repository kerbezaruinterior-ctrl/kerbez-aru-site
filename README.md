# Kerbez Aru — студия и школа дизайна

Объединены текущий сайт Kerbez Aru и сцена сборки квартиры из варианта 2.

## Просмотр и публикация
Готовая страница: `index.html` в корне. Запустите статический сервер из корня (`python -m http.server 4174`) или опубликуйте содержимое репозитория на статическом хостинге/GitHub Pages. Все файлы используют относительные пути, включая картинки, скрипты и шрифты. WhatsApp и YouTube остаются внешними сервисами.

## Редактирование
Node.js 20+, `npm ci`, затем `npm run build`. Исходники в `source/src/`. `npm test` — проверки целостности. Сборка не нужна для обычного просмотра опубликованной страницы.

Сцена #build: сетка → чертёж → планировка → стены → отделка → мебель → декор → свет. Сохранены pin, snap, гомография, SVG-рисование и исходные кадры. При reduced motion и без JS используется статичный контент.

Исходный вариант сохранён в `archive/variant-2/` с контрольными суммами. Отчёт проверки: `qa/REPORT.md`.
