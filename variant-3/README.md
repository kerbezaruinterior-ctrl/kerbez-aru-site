# Kerbez Aru — вариант 3 (образец для объединения)

Как вариант 2, плюс:
- на этапах сборки камера приближается к нужной зоне (планировка, паркет, гостиная, спальня);
- после этапа «Свет» камера «ныряет» в гостиную, и дальше прокрутка ведёт по 6 комнатам: гостиная-кухня → столовая → спальня → кабинет → ванная → прихожая;
- фото комнат в img/rooms/ сгенерированы по кадрам квартиры в разрезе, поэтому мебель и материалы совпадают.

Открыть: двойной клик по index.html или `python -m http.server 8080` в этой папке.
Все изображения — AI-концепты, не реализованные проекты.
