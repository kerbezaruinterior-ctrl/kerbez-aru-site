# AGENTS.md — Kerbez Aru, вариант 3

Статический сайт: один index.html (CSS и JS внутри), библиотеки в vendor/ (GSAP 3.13 + ScrollTrigger + SplitText, Lenis 1.1.13).

## Первый экран #build
- `.canvas > .cam > .cv`: холст 1344×752 px, `fit()` масштабирует его под ширину `.canvas`.
- `.cam` — «камера»: функция `shot(z, fx, fy)` даёт scale и смещение, чтобы точка (fx, fy) в долях холста оказалась в центре кадра при увеличении z. Хелпер `C(time, z, fx, fy, …)` добавляет движение камеры в таймлайн. На мобильных (≤900px) приближение ослаблено (`MOB`).
- Слои `.cv`: `#grid` → `#plan2d` (плоский план; наклоняется в 3D через гомографию `proj(SRC, quad)`, `FLAT` → `QUAD`) → `#lines` (векторный чертёж) → кадры `.fr3….fr7` из img/build/.
- `#roomsLayer .rm` — полноэкранные фото комнат из img/rooms/, появляются после «нырка».
- Таймлайн `T` (~14 единиц). Метки: `p0…p7` — этапы сборки, `r0…r5` — комнаты. ScrollTrigger с `pin`, `scrub` и `snap: 'labels'`.
- Тексты этапов — `#bStage .st[data-i]` (0…13), список справа — `.b-list li[data-i]` (1…8). Активный этап считается по массиву `starts`.
- На этапе «Свет» токены `--bb/--bt/--bt2` секции `#build` анимируются в вечерние; кадры 3–6 гасятся, чтобы у вечернего кадра не было светлого ореола.

## Правила
- Сохранять prefers-reduced-motion и статичный режим без класса `js-motion`.
- Проверять на ширине 1440 и 390 px.
