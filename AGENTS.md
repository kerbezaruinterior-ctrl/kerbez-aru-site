# AGENTS.md — Kerbez Aru, вариант 2

## Что это
Одностраничный статический лендинг студии дизайна интерьера Kerbez Aru (Астана). Язык контента — русский. Сборки нет: один `index.html` со встроенными CSS и JS, библиотеки лежат в `vendor/`.

## Стек
- HTML + CSS (custom properties) + vanilla JS.
- GSAP 3.13.0: `gsap`, `ScrollTrigger`, `SplitText` (`vendor/`).
- Lenis 1.1.13 — плавная прокрутка (`vendor/lenis.min.js`), синхронизирована с ScrollTrigger через `gsap.ticker`.
- Шрифты Google Fonts: Cormorant Garamond (заголовки), Golos Text (текст), IBM Plex Mono (подписи).

## Устройство index.html
1. `<head>`: шрифты, скрипты из `vendor/`, маленький inline-скрипт, который ставит класс `js-motion` на `<html>`, если GSAP загрузился и у пользователя НЕ включено `prefers-reduced-motion`.
2. `<style>`:
   - Токены цвета в `:root` + тёмная тема через `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`. Цвета брать только из токенов.
   - Секция `#build` (первый экран) имеет свои токены `--bb/--bt/--bt2` (фон/текст), они анимируются на этапе «Свет».
   - Правила под `.js-motion` = анимированная раскладка; без этого класса страница показывается статично. Не ломать статичный режим.
3. Разметка по секциям: `#build` → `#approach` (манифест) → бегущая строка → `#portfolio` (тёмная сцена с планом и 5 комнатами) → `#services` (стопка карточек) → `#materials` → `#process` → `#faq` → `#contact`.
4. `<script>` в конце: общий код (меню, форма → WhatsApp, копирование телефона), затем блок MOTION.

## Первый экран (#build) — как работает
- `.canvas > .cv` — «холст» 1344×752 px, масштабируется функцией `fit()` под ширину `.canvas`.
- Слои внутри `.cv` (снизу вверх): `#grid` (SVG-сетка), `#plan2d` (плоский план 600×440 в SVG), `#lines` (векторный аксонометрический чертёж, 69 path), `.fr3`…`.fr7` (кадры из `img/build/`).
- Плоский план «наклоняется» в 3D через `matrix3d`, вычисляемую гомографией (`proj(SRC, quad)`) из прямоугольника `FLAT` в четырёхугольник `QUAD` (углы стен на кадре). Если кадры заменят — пересчитать `QUAD` по углам стен нового кадра.
- Таймлайн `T` (≈8 единиц, по единице на этап) привязан к ScrollTrigger с `pin` и `snap: 'labels'`. Метки `p0…p7` — точки, где этап закончен; на них прокрутка «доводится».
- Тексты этапов — `#bStage .st[data-i]` (0…7), список справа — `.b-list li[data-i]`. Номер активного этапа считается в `onUpdate` по массиву `starts`.
- Кадры `img/build/*` сгенерированы цепочкой (каждый из предыдущего), чтобы совпадала геометрия. При замене — сохранять тот же ракурс и кадрирование 1344×752 и фон ≈ `#E2E0D7` (у вечернего кадра ≈ `#7B6757`).

## Правила правок
- Мелкие правки — точечно, не переписывать файл целиком.
- Сохранять: `prefers-reduced-motion`, статичный режим без `js-motion`, видимый фокус, alt у изображений, подпись «концепт-визуализация».
- Проверять на ширине 1440 и 390 px: нет горизонтальной прокрутки, этапы идут по порядку, текст не наезжает на изображение.
- Номер WhatsApp — константа `WA` в начале скрипта; формы не отправляют данные на сервер, а открывают wa.me с готовым текстом.
