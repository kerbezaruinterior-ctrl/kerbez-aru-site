# Kerbez Aru — сайт, вариант 2

Лендинг студии дизайна интерьера Kerbez Aru (Астана). Первый экран: квартира «строится» при прокрутке — сетка → чертёж → планировка → стены → отделка → мебель → декор → свет.

## Как открыть
Сборка не нужна, это обычный статический сайт.

1. Распакуйте архив.
2. Откройте терминал в папке `kerbez-aru-v2`.
3. Запустите локальный сервер (нужен Python 3):
   ```
   python3 -m http.server 8080
   ```
   На Windows: `py -m http.server 8080`
4. Откройте в браузере: http://localhost:8080

Можно и просто дважды кликнуть `index.html`, но через сервер поведение ближе к реальному хостингу.

## Работа через Codex
1. Установите Codex CLI (нужен Node.js 18+):
   ```
   npm install -g @openai/codex
   ```
2. В папке проекта запустите:
   ```
   codex
   ```
3. Codex сам прочитает `AGENTS.md` — там описано устройство сайта и правила правок.

Папка уже является git-репозиторием с первым коммитом: можно откатывать любые правки (`git log`, `git diff`, `git checkout -- .`).

## Структура
```
index.html          весь сайт: разметка, стили, скрипты
img/build/          кадры сборки квартиры (3-walls … 7-light)
img/*.jpg           фото комнат для блоков ниже первого экрана
vendor/             GSAP 3.13 (+ScrollTrigger, SplitText) и Lenis — локальные копии
AGENTS.md           инструкция для Codex
```

Все изображения — AI-концепты (не реализованные проекты студии), на сайте это подписано.
